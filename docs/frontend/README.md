# Frontend overview

The dashboard is a web UI for real‑time monitoring and historical analysis. We start with the setup and login flows to establish the visual language.

Current scope:
- Setup flow (storage selection, backup policy, owner account)
- Shared help popup component for context and onboarding

Planned scope:
- Live metrics per aquarium and per device
- Time‑range charts for temperature, pH, and TDS
- Read‑only demo access

The frontend will consume the backend endpoints documented in [API reference](../backend/api.md).
