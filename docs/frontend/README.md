# Frontend overview

The dashboard is a web UI for real‑time monitoring and historical analysis. It will be documented here once the frontend is added.

Keywords: `frontend` `dashboard` `charts` `real-time`
Back: [Docs hub](../README.md)

Planned scope:
- Live metrics per aquarium and per device
- Time‑range charts for temperature, pH, and TDS
- Read‑only demo access

The frontend will consume the backend endpoints documented in [API reference](../backend/api.md).
